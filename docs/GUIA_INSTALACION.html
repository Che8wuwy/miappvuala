MiAppVuala

Guía para publicar la app en GitHub Pages e instalarla en el celular. Versión 1.0.1.

1. Publicar en GitHub (una sola vez)

1Crea tu cuenta en github.com/signup (gratis). Confirma tu correo.
2Crea un repositorio: botón verde New (o “+” arriba a la derecha → New repository).
  • Repository name: miappvuala
  • Visibilidad: Public (GitHub Pages gratis lo requiere).
  • Marca Add a README file y da clic en Create repository.
Que sea público solo muestra el código de la app. Tus colecciones y códigos nunca se suben: viven únicamente en tu celular.
3Sube los archivos: dentro del repositorio, Add file → Upload files. Abre la carpeta MiAppVuala en tu PC, selecciona todo su contenido (index.html, sw.js, manifest.webmanifest y las carpetas css, js, icons, vendor, docs) y arrástralo a la página. Espera a que termine y da clic en Commit changes.
Arrastra el contenido, no la carpeta MiAppVuala completa. index.html debe quedar en la raíz del repositorio.
4Activa GitHub Pages: Settings → Pages. En Build and deployment: Source = Deploy from a branch, Branch = main y carpeta / (root). Da clic en Save. En 1 o 2 minutos aparece arriba la dirección: https://TU-USUARIO.github.io/miappvuala/

2. Instalar en el celular

5Con internet, abre esa dirección en Chrome del celular.
6Entra una vez a Capturar código: acepta el permiso de la cámara y espera a que diga “Lector listo”. Así queda descargado todo para usarse sin internet.
7Menú de Chrome (⋮) → Instalar app o Agregar a la pantalla principal. Aparece el ícono de MiAppVuala.
8Prueba sin internet: pon el celular en modo avión y abre la app desde el ícono. Debe funcionar igual.
Listo. Desde aquí ya no necesitas internet para capturar, consultar ni exportar.

3. Uso diario

PantallaQué hace
Capturar códigoEliges la colección (por defecto la creada más recientemente; puedes filtrar por año). Encuadras solo la primera línea del código en el recuadro y tocas Leer código. Revisas o corriges y tocas Verificar y guardar: verde si es nuevo, rojo si ya existía en esa colección.
ColeccionesAgregar, editar, archivar y restaurar. Archivar viene deshabilitado; se activa en Configuración.
ConsultarBuscar códigos dentro de la colección seleccionada, eliminar un código capturado por error (🗑️, pide confirmación) y descargar el CSV para Excel.
ConfiguraciónModo oscuro, color, tamaño de letra, vibración, permitir archivar, respaldo y acerca de.
Sobre el lector: la impresión de puntos de las bolsas es difícil de leer. La app propone el código (a veces hasta 3 opciones) y tú lo confirmas. Las confusiones típicas son 8/B, 0/O/D, 5/S y 1/I. Con buena luz, el celular quieto y el texto llenando el recuadro, la lectura mejora mucho. Siempre puedes usar Escribir a mano.
Respaldo: si borras los datos de Chrome, desinstalas la app o cambias de celular, los datos se pierden. Usa Configuración → Exportar respaldo de vez en cuando y guarda el archivo en Drive o en tu PC.

4. Publicar una actualización

  1. Cambia la versión en js/config.js (APP_VERSION) y en sw.js (CACHE_VERSION). Si agregaste archivos nuevos, agrégalos a la lista de sw.js.
  2. En GitHub: Add file → Upload files y sube los archivos modificados con la misma ruta (los reemplaza).
  3. En el celular, abre la app con internet: se actualiza sola y se recarga. Tus datos no se tocan.

5. Seguridad

  • No hay servidor ni base de datos en internet: nadie puede “entrar” a la app a robar información.
  • La app no se conecta a ningún sitio después de instalarse; una política de seguridad (CSP) bloquea cualquier archivo externo.
  • Los datos quedan aislados en el almacenamiento de Chrome para esa dirección; otras apps y páginas no pueden leerlos.
  • La cámara solo está encendida en la pantalla Capturar; se apaga al salir o cambiar de app.
  • Los respaldos importados se validan campo por campo y el CSV se protege contra fórmulas maliciosas en Excel.
  • Cuida tu cuenta de GitHub (activa la verificación en dos pasos): quien la controle podría cambiar el código de la app.
